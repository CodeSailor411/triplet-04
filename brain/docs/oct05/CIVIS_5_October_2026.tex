\textbf{Common rule:} physical actions require usable evidence and an exact-action Guardian token. Twin executes and enforces caps; high-risk actions need a preview. Guardian alone requests containment. If usable alternatives are unavailable, withhold actuation and log the incident.

\section*{3. CIVIS data conventions}
\begin{itemize}
\item \textbf{Format/identity:} UTF-8 JSON, \code{snake_case}; stable \code{run_id}, \code{reading_id}, \code{device_id}, \code{node_id}. \code{domains} allows multiple domains. Ignore extra fields; reject missing/wrong required fields.
\item \textbf{Time/location:} simulated UTC RFC 3339 timestamps, e.g. \code{2026-10-04T08:00:00.000Z}, plus integer \code{tick}; declare tick duration per run. Use \code{node_id}; optional WGS84 \code{latitude_deg}/\code{longitude_deg}.
\item \textbf{Values/units:} finite numbers with explicit quantity/unit: Traffic congestion index 0--100 \code{percent}; Water \code{cm} with local datum; Power load \code{kW}; Air PM2.5 \code{ug/m3}. Emergency events carry reported type, location, and transcript treated as data, never instructions.
\item \textbf{Missing/trust:} missing value is JSON \code{null}, never zero. Keep original readings and references for corrections. Guardian score stays numeric, with Guardian-declared scale/cut-offs; a score is not an action token.
\item \textbf{Actions:} \code{action}, \code{targets}, \code{token}, \code{idempotency_key}. Proposed \code{action} contains name/parameters; retain source reading references. Reuse the key only for retries of the same unchanged request.
\item \textbf{Cap discovery/counting:} read current limits from Twin capabilities; never hardcode table values. Action caps count distinct affected nodes per request in each applicable domain. Shared nodes count in each domain they belong to. Dispatch caps count nodes, not dispatched units.
\item \textbf{Containment:} isolation caps count the concurrent union of isolated and quarantined nodes per domain; a node in both counts once. \code{rollback_reading} is uncapped and affects one reading of one node. Power's all-node isolation cuts sensor data, not grid power.
\item \textbf{Cap failure/reset:} Twin rejects the entire over-cap request with \code{CAP_EXCEEDED}; no partial effects. Record \code{domain}, \code{cap}, \code{limit}, \code{already}, and \code{requested}. Do not retry an unchanged rejection. Isolation persists until run/scenario reset in the mock; no release call is specified.
\end{itemize}
\textbf{Pending interface agreements:} traffic/PM2.5 mapping, topology, action parameters, score scale, thresholds, and token lifetimes. Water level alone does not prove a leak; low load alone does not prove an outage. 9antra must confirm the proposed limits, shared containment pool, and reset-only lifecycle. Quarantine release behavior and counting fields for overlapping targets require explicit definition.
